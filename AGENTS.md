# Core Developer Instructions

1 Maintain absolute type safety with TypeScript
2 Keep all components clean and structured in modular files
3 Always implement real integrations with Firebase Authentication and Firestore
4 Never use mock data or fake database entries
5 Ensure every view is completely responsive on both mobile and desktop screens
6 Apply modern minimalist design with dark color schemes and Inter font
7 Use Space Grotesk for headings and JetBrains Mono for system readouts
8 Add smooth animations using the motion library for route transitions
9 Track and handle loading states and error events gracefully
10 Do not include external template code that deviates from user goals
